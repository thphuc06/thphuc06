### 💰 [Jars Platform](https://github.com/thphuc06/jar-platform)
<sub>Rewritten in Java from the Swinburne Top 4/260 prototype</sub>

- CSV import: S3 → EventBridge → SQS → Spring Batch
- AI advisor on Bedrock with read-only tools and Guardrails

### 🧊 [ColdStart Killer](https://github.com/thphuc06/ColdStart_Killer)
<sub>🏆 MongoDB Hackathon · Top 7/100</sub>

Hybrid RAG that recommends brand-new e-commerce products before they have any interactions.

- Vector search (BGE-M3) + BM25 fused with Atlas `$rankFusion`
- HyPE queries and item propositions generated by Qwen3:8b
- Item-item collaborative filtering served through FastAPI
- Evaluated 5 variants over 3,000 cold items: **NDCG@10 0.77**, **HitRate@10 0.78**, **116.5 ms P95**

### 🍽️ [FairTable](https://github.com/thphuc06/FairTable)
<sub>Amazon Developer Hackathon · Alexa+ track</sub>

A self-hosted MCP server that lets Alexa+ book independent restaurants without bots taking every table.

- 7 MCP tools; restaurant rules written as **Cedar** policies
- Spoken read-back confirmation before a hold becomes a booking
- "Fair Drop" lottery for popular tables, with a commit-reveal seed anyone can check
- 40-task evaluation: **0 violations**; red team: **12/12 attacks blocked**
- Runs with one `docker compose up`
